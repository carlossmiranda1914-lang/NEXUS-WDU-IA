# Nexus Documentation Archive

Files under `docs/archive/` preserve historical evidence, prior mission execution, superseded plans and tool-specific workflows.

## Rules

- Archive content is **not implementation authority**.
- Do not update archived files to make them look current; preserve historical meaning.
- Current decisions live in the canonical paths indexed by `docs/README.md`.
- When an archived rule remains valid, cite or restate it in a current canonical document rather than treating the archive as active policy.
- Historical evidence may be removed permanently only when it is an exact duplicate/generated artifact with no evidentiary value.

## Categories

- `missions/` — completed/superseded mission plans, logs and closeouts;
- `planning/` — superseded master plans/roadmaps;
- `tooling/` — tool-specific workflows/templates no longer governing the project;
- `evidence/` — completed micro-gates and evidence templates where historical retention matters.
