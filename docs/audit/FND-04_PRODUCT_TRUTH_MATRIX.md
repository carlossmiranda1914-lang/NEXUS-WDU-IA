## Implementation invariants

- Backend authorization, InstitutionalContext and FND-02/FND-03 fences stay authoritative.
- Client tenant, role, document, file and institution identifiers remain untrusted.
- A success state requires the actual command result and an appropriate authoritative read-back; a toast, timer, alert, localStorage write or sample row is insufficient.
- Canonical Enrollment/StudentProfile, Enrollment Documents and modular School Tasks remain functional and are regression controls for every relevant slice.
- A corrective treatment may hide, label, disable, redirect or fail factual; it must not invent Finance, Documents, IAM, Communication, AI, Workflow or integration domains.
